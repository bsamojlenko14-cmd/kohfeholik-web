# Kohfeholik — web kaviarne

Školský projekt na predmet **Návrh a tvorba webových stránok** (UNIZA), autor Bohdan Samoilenko (1ZD531).

Web fiktívnej kaviarne Kohfeholik v Žiline: ponuka s cenami a filtrom, catering, otváracie hodiny so stavom „teraz otvorené", online rezervácia stola s potvrdením, informácie o Wi-Fi a zásuvkách, mapa s navigáciou.

## Súbory

- `index.html` — domov: prečo u nás, z našej ponuky, kto sme, kontakt a mapa
- `ponuka.html` — ponuka a cenník s filtrom (horúce nápoje, dezerty a raňajky, chladené nápoje)
- `rezervacia.html` — rezervácia stola alebo catering, potvrdenie
- `styles.css` — vzhľad podľa `docs/style-guide.md`
- `script.js` — mobilné menu, filter menu, stav otvorenia, kontrola formulára, „Vyplniť ako minule" (localStorage)
- `docs/zadanie-webu.md` — design brief (zadanie webu z časti 1)
- `docs/style-guide.md` — vizuálny štýl
- `docs/prototyp/` — papierový prototyp, klikateľný wireframe (`index.html`) a obrázky obrazoviek
- `img/` — favicon a obrázky

Čisté HTML, CSS a JavaScript bez frameworkov. Žiadne heslá ani API kľúče.
